# Keyboard Shortcuts Guide

**FlexPM** - Comprehensive keyboard shortcuts for faster workflow

---

## 🎹 Global Shortcuts

These shortcuts work from anywhere in the application:

| Shortcut | Action | Description |
|----------|--------|-------------|
| `Ctrl+K` (or `⌘K` on Mac) | **Command Palette** | Open the command palette for quick access to all commands |
| `Esc` | **Close Modal** | Close any open modal or dialog |

---

## 📋 Board View Shortcuts

These shortcuts are available when viewing a board:

| Shortcut | Action | Description |
|----------|--------|-------------|
| `N` | **New Item** | Create a new item in the first column |
| `R` | **Refresh** | Reload the board data |
| `Ctrl+K` | **Command Palette** | Access all board commands |

---

## 🎨 Command Palette Commands

Press `Ctrl+K` to open the command palette and access these commands:

### Item Management
- **Create New Item** - Add a new item to the board (shortcut: `N`)
- **Add Item to [Column]** - Create item directly in a specific column
- **Refresh Board** - Reload board data (shortcut: `R`)

### Navigation
- **Go to Projects** - Navigate to projects list
- **Go to Home** - Navigate to home page

### Search & Filter
- Type to filter commands in real-time
- Use `↑` and `↓` arrow keys to navigate results
- Press `Enter` to execute the selected command
- Press `Esc` to close

---

## 🖱️ Mouse & Keyboard Combinations

### Drag and Drop
- **Click and drag** item cards to move between columns
- Hold `Shift` while dragging for visual feedback (planned)

### Navigation
- **↑/↓ Arrow Keys** - Navigate command palette results
- **Enter** - Select command in palette
- **Esc** - Close modals or command palette

## 🔧 Platform-Specific Notes

### macOS
- `Ctrl` key is replaced with `⌘` (Command key)
- Shortcuts display as: `⌘K`, `⌘N`, etc.

### Windows/Linux
- Uses standard `Ctrl` key
- Shortcuts display as: `Ctrl+K`, `Ctrl+N`, etc.

## 💡 Tips & Best Practices

### Quick Item Creation
1. Press `N` to quickly create an item
2. Or press `Ctrl+K` and search for "Add Item to [specific column]"

### Fast Navigation
1. Press `Ctrl+K` to open command palette
2. Type "go" to see navigation commands
3. Select with arrows and press `Enter`

### Efficient Workflow
1. Use `Ctrl+K` as your "command center"
2. Learn the single-key shortcuts (`N`, `R`) for frequent actions
3. Use `Esc` to quickly close any modal

## 🚀 Advanced Features

### Context-Aware Shortcuts
Keyboard shortcuts change based on context:

- **Global Context**: Available everywhere (e.g., `Ctrl+K`)
- **Board Context**: Available only on board view (e.g., `N`, `R`)
- **Modal Context**: Available when modal is open (e.g., `Esc` to close)

### Input Protection
- Shortcuts won't trigger when typing in text fields
- Exceptions: `Ctrl+K` and `Esc` work even in inputs
- This prevents accidental command execution while editing

## 🐛 Troubleshooting

### Shortcuts Not Working?

**Check if you're in an input field:**
- Most shortcuts are disabled while typing in text inputs
- Use `Esc` to exit the input first

**Browser conflicts:**
- Some browsers may intercept certain shortcuts
- Try using the command palette (`Ctrl+K`) as an alternative

**Modal is open:**
- Close any open modals with `Esc` first
- Or use the command palette which works in all contexts

### Command Palette Not Showing?

- Make sure you're using `Ctrl+K` (not just `K`)
- Check that no other modals are blocking it
- Try refreshing the page
